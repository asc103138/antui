# 115 學年度校內語文競賽專案規範與工作指引 (AGENTS.md)

## 專案基本資訊
- **專案名稱**：115校內語文競賽・選手全方位培訓教材系統
- **適用對象**：臺中市梧棲區中正國民小學【四年丙班】（亦可通用於全校其他年級）
- **關聯技能**：`school-language-contest-coach`（全域技能）
- **主要用途**：依據競賽辦法與指定題目，全自動產出「在校集中訓練（早修、午休）」與「平日回家作業＋週末假日自學增量」全套教材與自評表。

## 核心設計與編寫原則
1. **雙軌獨立輸出**：
   - **老師版**：教學操作指引、每日早午修教學重點、完整解答、評判標準（特優/優等/尚可）、週末自學指引與週一晨間統一驗收指標。
   - **學生版**：題目答案必須完全刪除/挖空（留白作答框），提供每日自評打卡記錄表與家長簽章欄。
2. **日程排程原則**：
   - 上學日落實微型集訓（早自修 20 分鐘正音/技巧 ＋ 午休 20 分鐘計時/實測）。
   - 平日回家作業每日 15~20 分鐘。
   - 遇到週末假日停課，一律自動切換為「居家自主自學與作業增量」（作業增量 A/B/C、家庭長輩互動評核）。
3. **格式與資安守則**：
   - 每次生成必須確保 Markdown (.md)、Word (.docx) 與原生 PDF (.pdf) 同步就緒。
   - 嚴禁洩漏學生真實個人隱私個資，落款一律以「臺中市梧棲區中正國小四年丙班 ○○○書」形式標註。
   - 遵守母庫 `AGENTS.md` 規範，收工時自動執行 stage、commit 與同步推送至線上 Git 遠端儲存庫。
