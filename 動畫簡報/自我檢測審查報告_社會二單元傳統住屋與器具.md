## 🎨 動效工藝審查報告 (Design Engineering Motion Review)

| Before | After | Why (物理真實修正原理) |
| :--- | :--- | :--- |
| 預設 `transition: all` | 明確指定 `transition: opacity 300ms cubic-bezier(0.16, 1, 0.3, 1), transform 300ms cubic-bezier(0.16, 1, 0.3, 1);` | 消除無差別重繪耗能，避免引發多餘 Layout/Repaint 卡頓。 |
| 元素從 `scale(0)` 憑空出現 | 入場起點鎖定為 `scale(0.96) translateY(12px)` 搭配 `opacity: 0` | 真實物理世界不存在零體積物體，微縮縮放進場符合自然視覺慣性。 |
| 進場使用線性或 `ease-in` | 全域進場採用強烈自訂曲線 `cubic-bezier(0.16, 1, 0.3, 1)` | `ease-in` 造成介面遲鈍拖泥帶水，強烈 `ease-out` 提供快速即時的靈敏操作回饋。 |
| 按鈕點擊無動態反饋 | 全域按鈕與可點擊卡片增加 `:active { transform: scale(0.97); }` | 模擬實體按鍵物理下壓阻尼反饋，明確傳達點擊確認訊號。 |
| 行動端觸控藍灰閃爍 | 加入全域 `-webkit-tap-highlight-color: transparent;` | 抹除手機瀏覽器原生點擊高亮遮罩，呈現原生 App 級別的高級質感。 |
| 傳統 100vh 行動視窗破版 | 採用 `100dvh` 與 `100svh` 雙軌適配 | 防止手機 Safari/Chrome 網址列或虛擬鍵盤推擠導致畫面位移破版。 |
| 控制項文字長按反白選取 | 加入 `user-select: none;` | 防止學生或教師在觸控螢幕快速操作時誤觸反白文字造成視覺破壞。 |
