## 🎨 動效工藝審查報告 (Design Engineering Motion Review)

嚴格依據 Emil Kowalski 動效工藝標準，產出動態物理修正對照表：

| Before | After | Why (物理真實修正原理) |
| :--- | :--- | :--- |
| 預設 `transition: all` | 指定 `transition: opacity 300ms cubic-bezier(0.16, 1, 0.3, 1), transform 300ms cubic-bezier(0.16, 1, 0.3, 1);` | 杜絕無差別重繪耗能，避免引發多餘 Layout/Repaint 導致掉幀。 |
| 元素從 `scale(0)` 憑空出現 | 入場起點鎖定為 `scale(0.96) translateY(12px)` 搭配 `opacity: 0` | 真實物理世界物體皆有體積，微縮進場符合人眼自然視差與空間慣性。 |
| 進場使用線性或 `ease-in` | 全域進場採用強烈自訂曲線 `cubic-bezier(0.16, 1, 0.3, 1)` | `ease-in` 會讓操作產生遲滯與黏膩感，強烈 `ease-out` 提供乾脆俐落的即時回饋。 |
| 按鈕點擊缺乏物理回饋 | 全域按鈕與卡片配置 `:active { transform: scale(0.97); }` | 模擬實體按鍵物理下壓阻尼反饋，給予操作者清晰的確認訊號。 |
| 行動端觸控藍灰閃爍 | 加入全域 `-webkit-tap-highlight-color: transparent;` | 抹除手機瀏覽器預設的點擊高亮色塊，營造原生 App 般的細膩質感。 |
| 傳統 100vh 行動視窗破版 | 採用 `100dvh` 與 `100svh` 雙軌動態適配 | 防止行動瀏覽器網址列或底部工具列展開/收合時造成版面垂直推擠破版。 |
| 觸控螢幕文字長按反白選取 | 互動按鍵加入 `user-select: none;` | 防止學生或教師在智慧大屏快速連點時誤觸文字反白框，維持畫面乾淨。 |
