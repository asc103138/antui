## 🎯 核心教學架構（100% 依據康軒四上真實課本）

### 2-1 傳統住屋篇（課本 P.32～P.41）
- **原住民族智慧建築**：
  - **排灣族 / 魯凱族【石板屋】**：取材山林黑灰板岩與頁岩，層層咬合堆疊，冬暖夏涼、抗強颱防地震，排煙防蟲防腐油膜，獲 WMF 世界文物守護名單（屏東霧臺舊好茶部落）。
  - **達悟族【半地下屋】**：向地底開挖深入半地下，平緩斜屋頂避開夏季強颱與狂暴海風，鵝卵石深溝迅速排水滲透。
  - **泰雅族【木竹傳統屋】**：就地取材竹木構築，通風防潮，適應潮濕山林環境（宜蘭縣武荖坑）。
- **漢人傳統住屋與空間格局**：
  - **【竹管仔厝】**：竹子作樑柱編竹夾泥，輕巧韌性佳（雲林縣麥寮鄉）。
  - **【土埆厝】**：黏土混合稻草米糠壓製土埆磚，石塊奠定基礎防潮，冬暖夏涼（新北市深坑區）。
  - **【住屋擴建三部曲】**：一條龍（單列一字形） ➔ 單伸手（一正身一護龍 L 型） ➔ 三合院（一正身兩護龍 U 型凹字形）。
  - **【三合院空間格局】**：正廳（祭拜神明祖先、接待客人）、臥室（長輩左廂房尊位、晚輩右廂房）、廚房大灶（炊煮餐食）、農具間（靠近牛棚豬舍便利勞作）、稻埕（曬穀聚會遊戲場所）、防風竹林（環繞屋後遮擋強風）。
  - **【傳統住屋的改變與再生】**：現代鋼筋混凝土大樓公寓 vs 古厝活化為民宿文化休閒體驗與家族返鄉祭祖文化傳承。

### 2-2 傳統生活器具篇（課本 P.42～P.47）
- **原住民族生活器物**：
  - **【木臼與木杵】**：整根原木鑿空成臼，多人節奏合作搗小米脫殼，凝聚部落情感。
  - **【竹編魚筌】**：前大後小喇叭錐形竹編，內層單向倒刺（倒鬚）陷阱，魚蝦游入無法逆向游出。
  - **【排灣族陶壺】**：百步蛇與乳突紋路，貴族專屬尊貴傳家寶。
  - **【阿美族陶鍋】**：耐高溫泥陶，炊煮野菜與熱湯。
  - **【排灣族連杯】**：雙人連杯共同飲酒，象徵同甘共苦與真誠友誼。
  - **【阿美族檳榔葉鞘食器】**：折疊檳榔葉鞘以竹籤固定，耐火燒煮野菜熱湯（石頭火鍋）。
- **漢人日常器具物盡其用**：
  - **【紅磚柴火大灶】**：大鐵鍋高溫燒柴蒸粿炊飯。
  - **【木柴灰燼悶地瓜】**：大灶餘溫燜烤地瓜，物盡其用不浪費能源。
  - **【灰燼做菜園肥料】**：草木灰混入土壤天然施肥防蟲害。
  - **【木製菜櫥水桶砧板】**：紗網透氣防蒼蠅塵土、堅固木製日常用品。
- **生活器具現代風貌與減塑實踐**：
  - **【現代塑膠】**：輕便便宜防水但不易分解。
  - **【臺灣海廢統計實證】**：寶特瓶第一、吸管、免洗餐具、塑膠袋。
  - **【生活減塑行動】**：自備環保杯餐具提袋，源頭減塑保護環境。
