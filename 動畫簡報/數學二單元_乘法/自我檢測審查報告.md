## 📊 動效工程工藝審查報告 (Emil Kowalski Design Engineering Review)

依據 `AGENTS.md` 規定之強制審查格式，針對本次數學 4-3 動畫簡報進行全套動效工藝審查：

| 檢驗項目 | Before（傳統粗糙做法） | After（物理真實感與工藝修正） | Why（物理與認知心理學原理） |
| :--- | :--- | :--- | :--- |
| **進場曲線** | 使用 `ease-in` 或線性 `linear`，元素慢速起步導致遲鈍感 | 全面採用強烈自訂曲線 `cubic-bezier(0.16, 1, 0.3, 1)` 與 `power3.out` | 真實物理世界受力物體具備初速度與回饋感，高速入場並柔和煞停能給予四年級學生即時操控響應 |
| **形體縮放** | 元素從 `scale(0)` 憑空放大出現 | 起始點嚴格鎖定 `scale(0.97)` 搭配 `opacity: 0` 漸層進場 | 真實世界沒有零體積物體，微幅縮放（97% ➔ 100%）既具備深度景深感，又杜絕突兀膨脹假象 |
| **屬性過渡** | 濫用 `transition: all` 造成無差別監聽 | 精準指定 `transition: transform 0.25s, opacity 0.25s, background-color 0.2s` | 避免觸發瀏覽器無謂的 Layout / Reflow 重排耗能，確保 60fps 滿幀流暢度 |
| **點擊微互動** | 按鈕與卡片點擊時無回饋假死 | 所有可點擊按鈕、導覽鍵與測驗卡片全面配置 `:active { transform: scale(0.97); }` | 提供指尖按下時的物理微彈反饋，證明介面已即時受理使用者指令 |
| **行動視窗高度** | 單純使用 `100vh` 造成手機網址列縮放時破版 | 全面配置 `min-height: 100dvh` / `100svh` | 兼容行動載具動態島、虛擬鍵盤與網址列伸縮，保持 16:9 完美舞台比例 |
| **行動端觸控** | 點擊按鈕出現瀏覽器預設藍灰色反白閃爍 | 全域配置 `-webkit-tap-highlight-color: transparent` | 消除原生點擊色塊干擾，呈現 Native App 頂級質感 |
| **文字誤選防護** | 長按按鈕或導覽列時文字被反白圈選 | 導覽按鈕與控制項鎖定 `user-select: none` | 防止學生在平板操作探索時意外觸發文字選取藍色游標 |
| **高頻快捷鍵** | 鍵盤切換投影片加入多餘延遲動效 | 瞬切幻燈片（300ms 內柔和轉場，支援左右箭頭、空白鍵連擊即時跳轉） | 避免課堂演講與學生翻頁探索時產生等待卡頓感 |
| **圖層交互安全** | 動態網格層與背景阻擋點擊 | 背景層配置 `pointer-events: none; z-index: 1;` | 確保所有互動卡片、按鈕與影片播放器均能順暢接收點擊事件 |
| **關鍵頁動態呈現** | 粗暴嵌入全片影音播放器（帶進度條、全片有聲、需手動點擊播放），破壞簡報流暢度與課堂節奏 | 重構為 Slide 6 關鍵概念【靜音版無控制條循環動畫】＋ 右側四大心法卡片速查對照 | 遵循 Emil Kowalski 工藝原則，動態應作為概念圖解的呼吸焦點（Ambient Motion Graphic），而非把影片播放器生硬插入簡報，達成隨翻隨看、零操作負擔與雙欄速查對照 |
