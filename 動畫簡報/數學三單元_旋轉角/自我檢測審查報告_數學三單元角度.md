## 📊 動效工程工藝審查報告 (Emil Kowalski Design Engineering Review)

依據 `AGENTS.md` 規定之強制審查格式，針對本次數學 3-5 動畫簡報進行全套動效工藝審查：

| 檢驗項目 | Before（傳統粗糙做法） | After（物理真實感與工藝修正） | Why（物理與認知心理學原理） |
| :--- | :--- | :--- | :--- |
| **進場曲線** | 使用 `ease-in` 或線性 `linear`，元素慢速起步導致遲鈍感 | 全面採用強烈自訂曲線 `cubic-bezier(0.16, 1, 0.3, 1)` | 真實物理世界受力物體具備初速度與回饋感，高速入場並柔和煞停能給予四年級學生即時操控響應 |
| **形體縮放** | 元素從 `scale(0)` 憑空放大出現 | 起始點嚴格鎖定 `scale(0.97)` 搭配 `opacity: 0` 漸層進場 | 真實世界沒有零體積物體，微幅縮放（97% ➔ 100%）既具備深度景深感，又杜絕突兀膨脹假象 |
| **屬性過渡** | 濫用 `transition: all` 造成無差別監聽與多餘重排 | 精準指定 `transition: transform 0.25s, opacity 0.25s, background-color 0.2s` | 避免觸發瀏覽器無謂的 Layout / Reflow 重排耗能，確保 60fps 滿幀流暢度 |
| **點擊微互動** | 按鈕與卡片點擊時無回饋假死 | 所有可點擊按鈕、導覽鍵、播放控制條與測驗選項全面配置 `:active { transform: scale(0.97); }` | 提供指尖按下時的物理微彈反饋，證明介面已即時受理使用者指令 |
| **行動視窗高度** | 單純使用 `100vh` 造成手機網址列縮放時破版 | 全面配置 `min-height: 100dvh` / `100svh` | 兼容行動載具動態島、虛擬鍵盤與網址列伸縮，保持 16:9 完美舞台比例 |
| **行動端觸控** | 點擊按鈕出現瀏覽器預設藍灰色反白閃爍 | 全域配置 `-webkit-tap-highlight-color: transparent` | 消除原生點擊色塊干擾，呈現 Native App 頂級質感 |
| **文字誤選防護** | 長按按鈕或導覽列時文字被反白圈選 | 導覽按鈕與控制項鎖定 `user-select: none` | 防止學生在平板操作探索時意外觸發文字選取藍色游標 |
| **高頻快捷鍵** | 鍵盤切換投影片加入多餘延遲動效 | 瞬切幻燈片（300ms 內柔和轉場，支援左右箭頭、空白鍵連擊即時跳轉） | 避免課堂演講與學生翻頁探索時產生等待卡頓感 |
| **圖層交互安全** | 動態網格層與背景阻擋點擊 | 背景層配置 `pointer-events: none; z-index: 1;` | 確保所有互動卡片、按鈕與影片播放器控制項均能順暢接收點擊事件 |
| **幾何圖形合理性** | 手繪或粗製 SVG 扇形角度扭曲、時針分針長度比例失真、圓弧起訖點未經三角運算 | 嚴格採用笛卡爾坐標系幾何三角換算（$x = cx + r \cos\theta$, $y = cy + r \sin\theta$），時針為半徑 55%、分針為半徑 85%，大格 30° 刻度嚴格精準 | 數學幾何教學不容毫釐誤差，真實比例能建立學生對角度張開程度的直觀正確認知，避免直覺偏差 |
| **嵌入動畫控制項** | 無控制按鈕或粗暴丟給原生黑色醜陋 controls 破壞整體 UI 風格 | 依使用者要求量身打造自訂設計工程播放面板：具備播放/暫停按鈕、可拖拉 Seek Bar 進度調整滑桿、精準時間碼 (`00:00 / 01:24`)、靜音/有聲切換與重新播放按鈕 | 兼顧自訂頂級美感與課堂彈性操控，教師可隨時停格解說關鍵概念，學生亦可自由拖拉倒帶複習 |
