## 🎯 核心教學重點

### 2-1 傳統住屋篇
- **原住民族智慧建築**：
  - **排灣族 / 魯凱族【石板屋】**：取材山林黑灰板岩與頁岩，層層咬合堆疊，冬暖夏涼、抗強颱防地震，門楣刻劃百步蛇祖靈圖騰。
  - **達悟族【半穴居地下屋】**：向地底開挖深入半穴居，緊貼地表流線型避開夏季強颱與冬季狂暴東北季風，地面搭建高架通風涼台，鵝卵石深溝迅速排水。
  - **泰雅族 / 太魯閣族【防鼠高腳穀倉】**：木柱挑高隔絕潮濕地氣，柱頂安裝圓形倒扣防鼠板，造成物理死角阻截老鼠偷吃小米。
- **漢人先民空間禮法**：
  - **【三合院】**：正身中央神明廳供奉祖先、左右護龍長幼分居（左尊右卑）、門前寬闊大埕曬穀聚會，體現宗法倫理。
  - **【土埆厝】**：黏土混合稻草、米糠、牛糞壓模曬乾成土埆磚，冬暖夏涼但怕雨水浸泡，下半部常墊大卵石。
  - **【街屋與騎樓（亭仔腳）】**：面寬狹窄縱深長，天井通風採光，臨街騎樓遮陽避雨，展現鄰里互助人情味。

### 2-2 傳統生活器具篇
- **原住民族巧思器物**：
  - **【木臼與木杵】**：整根原木鑿空成臼，多人節奏合作搗小米打麻糬，凝聚部落情感。
  - **【百步蛇紋陶壺】**：排灣魯凱貴族專屬傳家寶與神聖聘禮，象徵尊貴與祖靈守護。
  - **【竹編魚筌】**：前大後小的錐形竹編，內層單向倒刺（倒鬚）構造，魚蝦游入無法折返。
- **漢人家鄉日常器具**：
  - **【紅磚柴火大灶】**：大鐵鍋燒柴烹飪、炊年糕蒸粿、灶神信仰保佑家宅。
  - **【雙扇旋轉石磨】**：上下重石輪逆時針旋轉，剪切研磨在來米與黃豆成濃郁米漿。
  - **【手搖風鼓機】**：手搖扇葉吹出強風，比重差分離飽滿實穀垂直下墜、輕盈空包彈隨風飛出。
  - **【菜罩與防蟻菜櫥】**：竹篾透氣防蠅，四腳注水陶盤隔水斷路防蟻爬。
