# 國小四年級國語第六課《又遠又近的月亮》互動簡報與解說動畫 · 自我檢測審查報告

## 📊 動效工程工藝審查報告 (Emil Kowalski Design Engineering Review)

依據 `AGENTS.md` 規定之強制審查格式，針對本次動畫與簡報動態進行逐項檢視：

| 檢驗項目 | Before（傳統粗糙做法） | After（物理真實感與工藝修正） | Why（物理與認知心理學原理） |
| :--- | :--- | :--- | :--- |
| **進場曲線** | 使用 `ease-in` 或線性 `linear`，元素慢速起步導致遲鈍感 | 全面採用強烈自訂曲線 `cubic-bezier(0.16, 1, 0.3, 1)` 與 `power3.out` | 真實物理世界受力物體具備初速度與回饋感，高速入場並柔和煞停能給予使用者即時操控響應 |
| **形體縮放** | 元素從 `scale(0)` 憑空放大出現 | 起始點嚴格鎖定 `scale(0.96~0.97)` 搭配 `opacity: 0` 漸層進場 | 真實世界沒有零體積物體，微幅縮放（97% ➔ 100%）既具備深度景深感，又杜絕突兀膨脹假象 |
| **屬性過渡** | 濫用 `transition: all` 造成無差別監聽 | 精準指定 `transition: transform 0.25s, opacity 0.25s` | 避免觸發瀏覽器無謂的 Layout / Reflow 重排耗能，確保 60fps 滿幀流暢度 |
| **點擊微互動** | 按鈕與卡片點擊時無回饋假死 | 所有可點擊按鈕與選項全面配置 `:active { transform: scale(0.97); }` | 提供指尖按下時的物理微彈反饋，證明介面已即時受理使用者指令 |
| **行動視窗高度** | 單純使用 `100vh` 造成手機網址列縮放時破版 | 全面配置 `min-height: 100dvh` / `100svh` | 兼容行動載具動態島、虛擬鍵盤與網址列伸縮，保持 16:9 完美舞台比例 |
| **行動端觸控** | 點擊按鈕出現瀏覽器預設藍灰色反白閃爍 | 全域配置 `-webkit-tap-highlight-color: transparent` | 消除原生點擊色塊干擾，呈現 Native App 頂級質感 |
| **文字誤選防護** | 長按按鈕或導覽列時文字被反白圈選 | 導覽按鈕與控制項鎖定 `user-select: none` | 防止教學簡報演示與手勢操作時意外觸發文字選取藍色游標 |
| **高頻快捷鍵** | 鍵盤切換投影片加入多餘延遲動效 | 瞬切幻燈片（300ms 內柔和轉場，支援連擊即時跳轉） | 避免課堂演講與高頻翻頁時產生等待卡頓感 |
