# 校內國語文競賽全方位培訓教材生成技能 (School Language Contest Coach)

本技能專為各級學校（特別是國小第二、三學習階段與國中）語文競賽指導教師、級任導師與培訓團隊設計。
指導教師**只需提供比賽實施辦法（簡章）、出題範圍或範例題目**，本系統將自動進行法規解析、教學化拆解、時間軸排程，並產出**「老師教學指引（含詳解與評量標準）」**與**「學生實作學習單（答案完全挖空＋自評進度表）」**，支援 Word (.docx)、PDF (.pdf) 與 Markdown (.md) 全格式一鍵輸出。

---

## 壹、核心設計哲學與四大鐵律

### 1. 班級與年級客製化（避免年段混淆）
- 嚴格鎖定參賽年級（如四年級組排除五年級篇目，國中組排除高中篇目）。
- 文檔內落款與參賽身分均標準化（例如：「臺中市梧棲區中正國小四年丙班 ○○○書」）。

### 2. 雙軌檔案獨立架構
- 📂 **老師版**：《老師_指導指引與每日進度表(含評量標準).md / .docx / .pdf》
  - 提供在校早自修（正音、結構、筆法、心智圖）與午休（實測、計時、走位、問答）教案。
  - 包含完整標準答案、注音標音、臺羅拼音與變調詳解、420字示範講稿、評判 5 大問答詳解。
  - 包含特優（★★★）、優等（★★）、尚可（★）具體三級評量指標規準。
- 📂 **學生版**：《學生_在校教學練習每日學習單與自評表.md / .docx / .pdf》
  - **題目答案必須完全刪除挖空**（字音字形留白作答框、心智圖大綱填寫框、純漢字無注音朗讀稿、書法九宮格筆順練習）。
  - 提供每日打卡記錄表、秒數記錄、學生自評星等與家長簽章欄。

### 3. 「在校集訓 ＋ 假日自學增量」日曆聯動機制
- **在校集訓（週一至週五）**：微型集訓（早自修 20~35 分鐘 ＋ 午休 20~35 分鐘），兼顧常態教學與競賽培訓。
- **平日回家作業**：每日 15~20 分鐘高頻精熟任務，由家長簽章督導。
- **週末假日自學增量（六、日停課機制）**：
  - 遇到週末假日停課，自動切換為居家自主自學與高強度作業增量（作業增量 A、作業增量 B、作業增量 C）。
  - 包含長篇練筆、大型挖空測驗卷、宣紙全開實寫、全篇 10~12 遍計時朗讀、鏡前三大手勢、家庭長輩聽讀會等。
  - 老師版增設「週一晨間統一驗收指標規準」，確保訓練進度連續不脫節。

### 4. 三大格式完整交付
- **Markdown (.md)**：結構清晰，便於在線檢閱、Obsidian 雙鏈筆記收錄與快速複製。
- **Word (.docx)**：排版雅緻（微軟正黑體、教育部標準注音、高雅雙色表頭、精緻邊框），便於教師二度編輯。
- **高清 PDF (.pdf)**：調用 Windows Word COM 原生轉存，排版完全固定，方便直接送學校影印室雙面裝訂發送。

## 參、Agent 執行工作流程（SOP 四步驟）

當使用者要求建立或訓練國語文競賽選手時，執行以下標準作業流程：

### Step 1｜讀取簡章與範疇解析（必要資訊對齊）
向使用者索取或自對話中擷取以下核心資訊：
1. **競賽辦法**：包含競賽時間、地點、各組時限、評分比例（可提供 Word、PDF、圖片或文字）。
2. **範疇與篇目題目**：
   - 朗讀組指定文章篇目（國語、本土語）。
   - 演說組指定題目（國語、本土語情境題目或看圖題目）。
   - 字音字形出題範圍（年段、字數、歷屆題庫）。
   - 寫字組字樣（詩詞、格言、字數）。
3. **培訓對象與期程**：
   - 目標學校與班級（如：臺中市梧棲區中正國小四年丙班）。
   - 培訓起訖日期（例如：10/5 ~ 10/30，共 20 個在校日 ＋ 4 個週末假日）。
   - 每日在校培訓時段（例如：早自修 20 分鐘 ＋ 午休 20 分鐘）。

### Step 2｜建立專案目錄結構與資料庫
在專案目錄下自動建立標準資料庫目錄：
```
四年丙班_各項目培訓資料庫/
├── 01_寫字書法組/
├── 02_作文組/
├── 03_國語字音字形組/
├── 04_國語朗讀組/
├── 05_臺灣台語朗讀組/
├── 06_國語演說組/
└── 07_臺灣台語情境演說組/
```

### Step 3｜編寫高質量生成腳本並調用生成
調用本技能專屬之 Python 排版引擎（`scripts/generator.py` 與 `scripts/docx_styler.py`），生成 7 大項目之全套教材：
- 老師版 MD 與 DOCX（含每日教學重點、午休檢討、詳解、評量指標規準、週末自學指引）。
- 學生版 MD 與 DOCX（答案徹底挖空、逐日練習單、自評打卡記錄表、週末作業增量 A/B/C、家長簽章欄）。

### Step 4｜原生 PDF 高保真轉檔與最終交付
調用 Windows Word COM 物件（`scripts/pdf_converter.py`），將全部 14 份 Word 檔案轉換為原生高品質 PDF：
```powershell
python ~/.gemini/config/skills/school-language-contest-coach/scripts/pdf_converter.py --dir "<資料庫目錄>"
```
回報清晰的成果總表，列出 7 大項目、42 份文件之完整 `file:///` 連結。
