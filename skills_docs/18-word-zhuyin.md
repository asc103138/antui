# Word (.docx) 國字自動注音標註與學習單排版技能

專為國小語文教學、課本課文改編與低中年級閱讀學習單設計之自動化注音排版工具。徹底解決通用拼音工具對台灣繁體多音字（如：長度/ㄔㄤˊ vs 長大/ㄓㄤˇ、音樂/ㄩㄝˋ vs 快樂/ㄌㄜˋ、銀行/ㄏㄤˊ vs 行人/ㄒㄧㄥˊ、便宜/ㄆㄧㄢˊ vs 方便/ㄅㄧㄢˋ）的誤判問題。

---

## 核心能力與排版模式

1. **教育部多音字片語規則庫 (`scripts/zhuyin_dict.py`)**：
   - 最長片語優先匹配（Max-Match），精準鎖定上下文。
   - 自動記錄多音字查核日誌，產出終端複查表格。

2. **三種教學專用排版格式**：
   - **`table`（雙列表格模式，預設推薦）**：
     - 第一列為注音（字級 8.5pt、置中、行距緊湊，標點處空白）。
     - 第二列為國字（字級 16pt、標楷體粗體、置中）。
     - 邊框全隱藏，字音上下絕對對齊，適合低中年級閱讀學習單紙本列印。
   - **`ruby`（Word 原生旁註模式）**：
     - 以 `<w:ruby>` OpenXML 標籤直接嵌入段落行內，保留原始文章段落流動。
   - **`inline`（行內夾註模式）**：
     - 將文字標註為 `國字(注音)` 格式，適合教案與純文字講義。

## 常用指令範例

### 1. 單檔轉換（預設雙列表格模式）
```bash
python ~/.gemini/config/skills/18-word-zhuyin/scripts/word_zhuyin_annotator.py "教材.docx"
```

### 2. 指定排版模式
```bash
# 格式 A：雙列表格模式 (小學列印學習單推薦)
python ~/.gemini/config/skills/18-word-zhuyin/scripts/word_zhuyin_annotator.py "教材.docx" --mode table

# 格式 B：Word 原生注音標記 (Ruby)
python ~/.gemini/config/skills/18-word-zhuyin/scripts/word_zhuyin_annotator.py "教材.docx" --mode ruby

# 格式 C：行中夾註模式 如「長(ㄓㄤˇ)大」
python ~/.gemini/config/skills/18-word-zhuyin/scripts/word_zhuyin_annotator.py "教材.docx" --mode inline
```

### 3. 整體資料夾批次處理
```bash
python ~/.gemini/config/skills/18-word-zhuyin/scripts/word_zhuyin_annotator.py --folder "D:/教材資料夾/" --mode table
```
