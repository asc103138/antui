# RDQ 需求規格：智高 T082R 等臂天平互動 3D 組裝指南

## 一句話任務
依據三年級數學《公斤與公克》教案，打造一套嚴格符合**智高 T082R** 真實零件規格、可承重 **500g–1kg** 供教師示範的「網頁版互動 3D 等臂天平組裝指南」。

## ✅ 已確認
- 依據 [三年級steam教案.docx](../三年級steam教案.docx)（南一三下第六單元《公斤與公克》3 節課）設計等臂天平機關（Ⅰ）
- 嚴格符合智高積木真實零件種類、20mm 模組孔距與真實組裝卡榫邏輯，不可幻想零件（Ⅰ）
- 交付形態：**網頁版互動 3D 組裝指南**（支援 360° 旋轉、逐步拆解檢視積木卡榫與孔位）（Ⅲ）
- 零件範圍：以 **智高 T082R 機關王基本組** 零件種類為主，**教室有多盒可混用**（不限單盒單一零件數量）（Ⅲ）
- 使用定位：**教師示範用教具**，結構須強化穩固，能實際承載較重物品（**500g–1kg**，如課本、米袋等）（Ⅲ）

## ❓ 假設（未確認，已採預設值，隨時可推翻）
- 網頁形式與路徑 → 預設輸出為**互動網頁（Three.js）**存放於 `steam成果製作/gigo_balance_3d/`，並符合專案設計工程規範與 Playwright 實機驗收
- 零件規格核對 → 預設下載並比對**智高官方零件表（gigotoys.com）**之真實編號、名稱與標準 20mm 孔距尺寸，於頁面附上完整 BOM 清點表
- 承重 500g–1kg 機構策略 → 預設採**寬大強化底盤＋雙側三角斜撐塔架＋雙層並聯橫樑＋長軸轉動支點＋大型底板托盤**，避免橫樑下彎或傾倒
- 等重小積木砝碼規格 → 預設鎖定 **C-20mm 基本方塊**（單顆重量一致）預留 **20–30 顆**不進主結構，並於 3D 網頁附帶「左右放物與加減小積木平衡動態模擬」

## 📋 一段式需求規格
本專案為臺中市梧棲區中正國小 **115 年度 STEAM 教師社群**之三年級數學《**公斤與公克**》教案配套成品，目標是產出一套存放於 **`steam成果製作/gigo_balance_3d/`** 的**網頁版互動 3D 組裝指南**。模型結構須 100% 依據**智高積木 T082R 機關王基本組**之真實零件種類與 20mm 模組幾何規格設計（教室多盒可混用、不限單盒數量），經官方零件清單核對並標註真實品名與型號，確保實體確實組裝得出來且能順暢擺動；結構定位為**教師示範用高承重等臂天平**，須能穩定承載 **500g–1kg** 實物，並額外鎖定單一款小積木（預留 **20–30 顆**不進主結構）作為教案第 3 節的等重加減砝碼單位。網頁提供 360° 視角操作、分步組裝拆解動畫、零件 BOM 清點表與左右配重平衡模擬，且不產出紙本說明書、指針歸零滑塊、懸掛吊籃托盤與排錯卡。

- [ ] 3D 結構具備寬底盤、雙側支撐與強化等臂橫樑，物理上能支撐 **500g–1kg** 並清楚顯示每個卡榫／軸孔連接點
- [ ] 網頁支援 360° 旋轉縮放、逐步組裝／拆解切換、BOM 清單對照與小積木加減平衡示範
- [ ] 通過 `python scripts/audit_gatekeeper.py` 門禁檢查與 Playwright 瀏覽器實機渲染零錯誤驗收
